# Task Overview

This repository contains my solution for Task 1 – Data Cleaning & Preprocessing from the Data Analyst Internship program.

The objective of this task is to clean and prepare a raw dataset by handling missing values, removing duplicate records, fixing inconsistent formats, and standardizing the overall structure.
The task demonstrates practical skills in data cleaning, which is the first and most crucial step in any data analysis workflow.

🎯 Objective

Identify missing values

Remove duplicates

Fix inconsistent formats (text, numbers, dates)

Standardize column names

Correct data types

Produce a clean dataset ready for analysis

Provide a summary of all changes done
